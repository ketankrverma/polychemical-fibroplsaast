## 🌟 Overview

A modern, high-performance, and responsive corporate website for **Polychemical Fibroplast Private Limited**, engineered with Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, Three.js 3D WebGL graphics, and Lucide React icons.

### 🚀 Key Highlights & Technologies

- **Interactive 3D Three.js CAD Visualizer**: Real-time 360° interactive composite enclosure model with animated laser metrology scanning, wireframe/solid toggle, and holographic engineering annotations.
- **3D Material Architecture Explorer**: Exploded isometric 3D layer matrix for SMC, BMC, and FRP composite compounds with dynamic mechanical & electrical radar comparisons.
- **Mouse-Tracking 3D Tilt Cards**: Perspective physics and specular glare reflection on product, capability, and gallery cards.
- **Complete Product Catalog**:
  - FRP Industrial Products
  - SMC Compression Moulded Components
  - BMC Precision Moulded Switchgear
  - Industrial Fiberglass Reinforced Parts
  - Matched Die Composite Structural Components
  - Custom OEM Tooling & Mould Development
- **Interactive Lightbox Photo Gallery**: Full-screen preview, keyboard navigation, and technical metadata.
- **Comprehensive Sector Portfolios**: Automotive, Electrical Transmission, Construction, Aerospace & Defense, Industrial Machinery, and Urban Transit.
- **Interactive RFQ & Contact Desks**: Form validation with ticket generation and quotation routing.

## 💻 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ketankrverma/polychemical-fibroplsaast.git
cd polychemical-fibroplsaast
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 4. Build for production

```bash
npm run build
npm run start
```
